# Fundsroom ERP & CRM Management System

A web-based ERP and CRM management system designed to manage employees, customers, business operations, and reports through a centralized dashboard.

## 🚀 Project Overview

Fundsroom ERP & CRM is a full-stack web application developed to simplify business management activities.

The system provides a dashboard-based interface for managing:

- Employees
- Customers
- Business Operations
- Reports
- User Login
- Overall business information

The project follows a modern frontend-backend architecture with React on the frontend and Node.js/TypeScript on the backend.
